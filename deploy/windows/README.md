# Запуск бота на Windows-компьютере круглосуточно

Бот ставится как фоновая задача Планировщика заданий Windows:

- запускается при включении компьютера — ещё до входа в систему, от системной учётной записи (SYSTEM);
- если бот упал или стартовал без сети — перезапускается через 15 секунд (`run.cmd`), а если остановился сам `run.cmd` — Планировщик поднимает его снова через минуту;
- хранит всё на диске D (если его нет — на C): папка `D:\TaskReminderBot` — jar, конфиг, база артефактов и лог `logs\bot.log` (с датой и временем; при 10 МБ старый лог переименовывается в `bot.log.1`).

Сторонние программы не нужны.

## Что нужно

- Windows 10/11, права администратора (только для установки, обновления и удаления).
- Java 21+. Скрипт ищет её по порядку: параметр `-JavaHome`, `JAVA_HOME`, `D:\Java\*`, `C:\Program Files\…`
  и в последнюю очередь JDK из IntelliJ IDEA (`%USERPROFILE%\.jdks` — IDEA может удалить или обновить их).
  На этом компьютере уже есть `D:\Java\temurin-21.0.9` — он и будет использован. Другой вариант — отдельная установка:
  ```powershell
  winget install EclipseAdoptium.Temurin.21.JRE
  ```
- Собранный jar (`mvn -DskipTests package`) и заполненный `config.properties` в папке проекта.

## Установка

1. **Остановите бота, запущенного из IDEA** — с одним токеном может работать только один экземпляр
   (иначе ошибка `409 Conflict` и двойные напоминания). Скрипты предупредят, если найдут другой экземпляр.
2. Откройте **PowerShell от имени администратора** и выполните из папки проекта:
   ```powershell
   cd C:\Users\vsugo\IdeaProjects\task-reminder-bot
   powershell -ExecutionPolicy Bypass -File deploy\windows\install.ps1
   ```
   Скрипт:
   - копирует jar, `run.cmd` и `config.properties` в `D:\TaskReminderBot` (существующий конфиг там не перезаписывается);
   - оставляет доступ к конфигу с токеном только системе, администраторам и вам;
   - регистрирует задачу `TaskReminderBot`, запускает её и ждёт в логе строку `Bot started`.

   Параметры: `-InstallDir E:\Bots\Reminder` — другая папка (по умолчанию `D:\TaskReminderBot`, без диска D — `C:\TaskReminderBot`),
   `-JavaHome "D:\Java\temurin-21.0.9"` — конкретная Java.

3. **Отключите сон** — спящий компьютер напоминания не отправит. В PowerShell от администратора (при питании от сети):
   ```powershell
   powercfg /change standby-timeout-ac 0
   powercfg /change hibernate-timeout-ac 0
   ```
   Для ноутбука также: Панель управления → Электропитание → «Действие при закрытии крышки» → «Действие не требуется» (от сети).
   Обновления Windows могут перезагрузить компьютер — бот после перезагрузки поднимется сам.

## Повседневное

| Что | Команда (из папки проекта) |
|---|---|
| Состояние, память, последние строки лога | `powershell -ExecutionPolicy Bypass -File deploy\windows\status.ps1` |
| Обновить после изменений в коде (собрать и перезапустить) | `powershell -ExecutionPolicy Bypass -File deploy\windows\update.ps1 -Build` *(админ)* |
| Перезапустить | `Stop-ScheduledTask TaskReminderBot; Start-ScheduledTask TaskReminderBot` *(админ)* |
| Удалить задачу (файлы остаются) | `powershell -ExecutionPolicy Bypass -File deploy\windows\uninstall.ps1` *(админ)* |
| Удалить задачу и файлы | `... uninstall.ps1 -RemoveFiles` *(админ)* |

- **Настройки** правьте в `D:\TaskReminderBot\config.properties` (не в папке проекта — она больше не используется) и перезапустите бота.
- `update.ps1 -Build` использует `mvn` — он должен быть доступен в PATH.
- Задачу видно и в «Планировщике заданий» (`taskschd.msc`) → «Библиотека планировщика» → `TaskReminderBot`.

## Ограничения

- Если компьютер был выключен или спал в момент напоминания, это напоминание бот не пришлёт.
- Таймеры удаления сообщений и снятия закрепа хранятся в памяти: при перезапуске бота ожидающие удаления пропадут — такие сообщения удалите вручную.
