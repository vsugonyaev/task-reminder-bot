# task-reminder-bot (Java + Telegram + Quartz)

Напоминает команде о закрытии задач в рабочие дни спринта (время по умолчанию — МСК, Europe/Moscow).

- Спринты по 2 недели, идут друг за другом: 07.10–20.10.2026, 21.10–03.11.2026 и т.д. (начало и длина — в конфиге).
- В первый рабочий день спринта (обычно среда, планирование) в **10:00** (по умолчанию) приходит предупреждение: задачи сегодня не закрывать, а если закрыли — сразу писать скраму. Оформлено красным «стоп»-баннером, чтобы не путать с напоминаниями.
- В остальные рабочие дни спринта в **16:30** (по умолчанию) — напоминание закрыть задачи.
- Выходные, праздники и переносы берутся из производственного календаря РФ ([isdayoff.ru](https://isdayoff.ru)); рабочие субботы считаются рабочими. Если API недоступен — используются выходные + фиксированные федеральные праздники.
- Тексты с юмором меняются каждый день и не повторяются в пределах спринта; в последний день спринта — отдельный «финальный» текст.
- Сообщение закрепляется без звука и автоматически открепляется в 23:59 того же дня (`unpin.time`).
- За 5 минут до встреч команды приходит напоминание со ссылкой и кнопкой «Подключиться»; оно не закрепляется и удаляется из чата через 5 минут:
  - первый день спринта — планирование;
  - последний день спринта — обзор спринта;
  - остальные рабочие дни — дейлик.

  Время, комнаты и название команды задаются в конфиге (`meeting.*`).
- Хранит ссылки на документы (артефакты) по эпикам — см. раздел «Артефакты эпиков».

## Требования
- Java 21+
- Maven 3.8+

## Настройка
Создайте бота в @BotFather и получите токен.
Чтобы бот мог закреплять сообщения, сделайте его администратором группы с правом «Закреплять сообщения».

Все настройки лежат в `config.properties` (UTF-8):

1. Скопируйте `config.example.properties` в `config.properties`. Он в `.gitignore`, секреты в git не попадут.
2. Заполните `telegram.token` и `telegram.chat-id`, остальное — по желанию: время напоминаний и открепления, часовой пояс, начало и длина спринта, ник скрама, длительность закрепа для `/test`. Описание каждого ключа — в самом файле.

Бот ищет `config.properties` в текущей папке. Другой путь можно указать переменной окружения `CONFIG_FILE`.
Токен и id чата можно задать переменными окружения `TG_BOT_TOKEN` и `TG_CHAT_ID` — они важнее значений из файла.
Если настройка не задана, используется значение по умолчанию (как в примере); при ошибке в значении бот не стартует и пишет, какой ключ неверный.

### Как получить chatId группы
1. Добавьте бота в группу
2. Напишите в группе команду: `/chatid`
3. Бот ответит `chatId: ...` — это значение и нужно

## Команды
- `/chatid` — показать id текущего чата (работает в любом чате)
- `/sprint` — даты текущего спринта, дни напоминаний и встреч
- `/test` — показать, как будет выглядеть ближайшее напоминание (закреп на `test.pin-minutes` минут, только в рабочем чате)
- `/test start` — то же для предупреждения первого дня спринта
- `/test daily`, `/test planning`, `/test review` — показать напоминание о встрече (удалится через `meeting.delete-after-minutes` минут)

## Артефакты эпиков
Ссылки на документы по эпикам (SA, BA, макеты, ТПиС, ПТР, ПМИ, ПСИ, ТКР, ТИС, АР, АИС, Тест-план к4) хранятся в SQLite-файле `artifacts.db` рядом с ботом. Бэкап — копия этого файла.

| Команда | Что делает |
|---|---|
| `/artifacts` | выбрать эпик → список ссылок по всем типам (удаляется через 5 минут) |
| `/artifact_add` | выбрать эпик или создать новый (`STRLPL-123 Название`) → тип → ссылка. Если ссылка такого типа уже есть — спросит, добавить ещё одну или заменить |
| `/artifact_edit` | выбрать эпик → артефакт → заменить ссылку или удалить |
| `/epic_archive` | отправить эпик в архив (пропадает из списков) |
| `/artifacts_archive` | ссылки по архивным эпикам |

- Работают только в рабочем чате. Меню на кнопках; нажимать их может только тот, кто вызвал команду.
- Эпик можно найти, прислав номер или часть названия. При создании нового бот ищет похожие по названию и номеру и предлагает выбрать существующий.
- После завершения, отмены или 10 минут бездействия бот удаляет все сообщения диалога, включая сообщения пользователя.
- Из базы ничего не удаляется: эпики архивируются, удалённые ссылки помечаются удалёнными, вся история изменений (кто, когда, старая и новая ссылка) пишется в таблицу `artifact_history`.
- Боту нужны права администратора группы: «Удалять сообщения» (чистка диалогов) и «Закреплять сообщения». Как админ он также видит обычные сообщения — это нужно, чтобы принять ссылку.
- Типы артефактов, префиксы ключей эпиков, таймауты — в конфиге (`artifacts.*`).

## Запуск в IntelliJ IDEA
1. File → Open → выберите папку проекта
2. Дождитесь импорта Maven, в Project Structure выберите SDK 21
3. Run → Edit Configurations… → добавьте Application:
   - Main class: `com.example.Main`
   - Working directory: папка проекта (там лежит `config.properties`)
4. Run

## Сборка fat-jar
```bash
mvn -DskipTests package
java -jar target/task-reminder-bot-1.1.0.jar
```
